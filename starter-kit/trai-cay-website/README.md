# Hệ thống đào tạo tày năng
Dây là một hệ thống sinh ra nhằm **đào tạo** và tìm kiếm những người có ***tày năng***
| Thư mục | Nội dung |
| :---: | :---: |
| docs | Lưu trữ tài liệu hướng dẫn tân thủ |
| data | Lưu trữ các giữ liệu quan trọng |
| logs | Lưu trữ các bản báo cáo sự cố |

```shell
ls
```
